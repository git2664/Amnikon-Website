Frequently Asked Questions

Your questions, answered

Can you improve an existing website or application?

Yes. We can start with an assessment of the existing experience, code and integrations, then agree a phased improvement plan.

Can you connect our existing business systems?

We review available APIs, data ownership, access and vendor constraints before proposing an integration approach.

Will the solution work on mobile devices?

Responsive layouts and testing across agreed screen sizes are part of the proposed scope. Accessibility requirements can be defined during discovery.

Who owns the application and its documentation?

Ownership, source access, hosting, licensing and handover deliverables are agreed in the project scope before work begins.
